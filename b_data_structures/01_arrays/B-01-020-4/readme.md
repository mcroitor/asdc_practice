# Игра

На доске размером N x M  записаны целые числа ($0 \leq a[i][j] \leq 1000$). На клетку $(0, 0)$ установлена белая фишка, а на клетку $(N-1, M-1)$ установлена чёрная фишка. Коля и Саша по очереди делают ходы, Коля - белой фишкой, а Саша - чёрной фишкой. За один ход игрок может переместиться на любую соседнюю ячейку (вверх, вниз, влево или вправо), на которой ещё никто не был. Каждый игрок накапливает сумму чисел, находящихся в ячейках, в которых он побывал. Оба игрока играют оптимально, стремясь максимизировать свою сумму. Определите, кто выиграет при данных начальных условиях.

1. Гарантируется, что $N \times M \equiv 0 \pmod{2}$
2. Игра заканчивается, когда текущий игрок не может сделать ход (все соседние клетки уже посещены).

## входные данные

В первой строке даны два натуральных числа __N__ и __M__ — количество строк и столбцов матрицы ($1 \leq N, M \leq 100$).
Следующие __N__ строк содержат по __M__ целых чисел — элементы матрицы ($0 \leq a[i][j] \leq 1000$).

## выходные данные

Вывести в одной строке, разделённые пробелом, очки первого и второго игрока.

## ограничения

* $N \times M \equiv 0 \pmod{2}$
* $1 \leq N, M \leq 100$
* $0 \leq a[i][j] \leq 1000$
* time limit: 2s
* memory limit: 64m

## пример

| INPUT                                           | OUTPUT |
| ----------------------------------------------- | ------ |
| 2 2<br>1 2<br>3 4                               | 4 6    |
| 2 3<br>0 1 1<br>1 1 0                           | 2 2    |
| 4 4<br>1 0 1 0<br>2 1 1 1<br>0 1 3 0<br>1 0 0 2 | 8 9    |

## пояснение к примеру 3

1. Коля начинает на (0,0) с 1 очком.
2. Саша начинает на (3,3) с 2 очками.
3. Коля идёт на (1,0) с 3 очками.
4. Саша идёт на (2,2) с 5 очками.
5. Коля идёт на (1,1) с 4 очками.
6. Саша идёт на (2,1) с 6 очками.
7. Коля идёт на (1,2) с 5 очками.
8. Саша идёт на (2,3) с 7 очками.
9. Коля идёт на (1,3) с 6 очками.
10. Саша идёт на (3,2) с 8 очками.
11. Коля идёт на (3,1) с 7 очками.
12. Саша идёт на (3,0) с 9 очками.
13. Коля идёт на (2,0) с 8 очками.
14. Саша не может ходить, игра заканчивается.
