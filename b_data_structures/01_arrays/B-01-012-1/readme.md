# Инверсия диапазона

Дан массив целых чисел. Выполните инверсию (разворот) элементов на отрезке от индекса L до R включительно.

## входные данные

В первой строке дано натуральное число __N__ — количество элементов в массиве (1 ≤ N ≤ 100000).
Во второй строке даны __N__ целых чисел, разделенных пробелами — элементы массива (-10^9 ≤ a[i] ≤ 10^9).

В третьей строке даны два целых числа __L__ и __R__ (0 ≤ L ≤ R < N) — границы отрезка для инверсии.

## выходные данные

Вывести элементы массива после инверсии отрезка, разделяя пробелами.

## ограничения

* 1 ≤ N ≤ 100000
* 0 ≤ L ≤ R < N
* -10^9 ≤ a[i] ≤ 10^9
* time limit: 1s
* memory limit: 64m

## пример

| INPUT | OUTPUT |
| ----- | ------ |
| 5<br>1 2 3 4 5<br>1 3 | 1 4 3 2 5 |
| 6<br>10 20 30 40 50 60<br>0 5 | 60 50 40 30 20 10 |
| 4<br>1 2 3 4<br>2 2 | 1 2 3 4 |
