# Удаление дубликатов

Дан массив целых чисел. Удалите из него все дубликаты, оставив только первые вхождения каждого элемента.

## входные данные

В первой строке дано натуральное число __N__ — количество элементов в массиве (1 ≤ N ≤ 100000).
Во второй строке даны __N__ целых чисел, разделенных пробелами — элементы массива (-10^9 ≤ a[i] ≤ 10^9).

## выходные данные

Вывести элементы массива без дубликатов в порядке их первого появления, разделяя пробелами.

## ограничения

* 1 ≤ N ≤ 100000
* -10^9 ≤ a[i] ≤ 10^9
* time limit: 1s
* memory limit: 64m

## пример

| INPUT | OUTPUT |
| ----- | ------ |
| 7<br>1 2 3 2 4 1 5 | 1 2 3 4 5 |
| 5<br>5 5 5 5 5 | 5 |
| 6<br>10 -5 3 10 -5 8 | 10 -5 3 8 |
