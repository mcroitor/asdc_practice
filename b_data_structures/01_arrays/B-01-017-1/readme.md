# Симметричная матрица

Дана квадратная матрица целых чисел. Проверьте, является ли она симметричной относительно главной диагонали (т.е. $a[i][j] = a[j][i]$ для всех i, j).

## входные данные

В первой строке дано натуральное число __N__ — размер квадратной матрицы ($1 \leq N \leq 1000$).
Следующие __N__ строк содержат по __N__ целых чисел — элементы матрицы ($-10^9 \leq a[i][j] \leq 10^9$).

## выходные данные

Вывести `YES`, если матрица симметрична относительно главной диагонали, иначе `NO`.

## ограничения

* $1 \leq N \leq 1000$
* $-10^9 \leq a[i][j] \leq 10^9$
* time limit: 1s
* memory limit: 64m

## пример

| INPUT | OUTPUT |
| ----- | ------ |
| 3<br>1 2 3<br>2 5 6<br>3 6 9 | YES |
| 3<br>1 2 3<br>4 5 6<br>7 8 9 | NO |
| 2<br>5 0<br>0 5 | YES |
