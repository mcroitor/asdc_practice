# Минимум и максимум на отрезке

Дан массив целых чисел и несколько запросов. Для каждого запроса нужно найти минимальный и максимальный элементы на отрезке от индекса L до R включительно.

## входные данные

В первой строке дано натуральное число __N__ — количество элементов в массиве (1 ≤ N ≤ 100000).
Во второй строке даны __N__ целых чисел, разделенных пробелами — элементы массива (-10^9 ≤ a[i] ≤ 10^9).

В третьей строке дано натуральное число __Q__ — количество запросов (1 ≤ Q ≤ 100000).
Следующие __Q__ строк содержат по два целых числа __L__ и __R__ (0 ≤ L ≤ R < N) — границы отрезка.

## выходные данные

Для каждого запроса вывести минимальный и максимальный элементы на отрезке от __L__ до __R__ через пробел.

## ограничения

* 1 ≤ N ≤ 100000
* 1 ≤ Q ≤ 100000
* 0 ≤ L ≤ R < N
* -10^9 ≤ a[i] ≤ 10^9
* time limit: 1s
* memory limit: 64m

## пример

| INPUT | OUTPUT |
| ----- | ------ |
| 5<br>3 1 4 2 5<br>3<br>0 2<br>1 4<br>0 4 | 1 4<br>1 5<br>1 5 |
| 4<br>10 -5 3 7<br>2<br>0 3<br>1 2 | -5 10<br>-5 3 |
