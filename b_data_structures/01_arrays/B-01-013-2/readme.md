# Седловая точка

Дана матрица целых чисел. Найдите седловую точку — элемент, который является максимальным в своей строке и минимальным в своем столбце.

## входные данные

В первой строке даны два натуральных числа __N__ и __M__ — количество строк и столбцов матрицы (1 ≤ N, M ≤ 1000).
Следующие __N__ строк содержат по __M__ целых чисел — элементы матрицы (-10^9 ≤ a[i][j] ≤ 10^9).

## выходные данные

Если седловая точка существует, вывести её значение и позицию (номер строки и номер столбца, нумерация с 0).
Если седловых точек несколько, вывести любую из них.
Если седловых точек нет, вывести `NONE`.

## ограничения

* 1 ≤ N, M ≤ 1000
* -10^9 ≤ a[i][j] ≤ 10^9
* time limit: 1s
* memory limit: 64m

## пример

| INPUT | OUTPUT |
| ----- | ------ |
| 3 3<br>1 2 3<br>4 5 6<br>7 8 9 | NONE |
| 3 3<br>5 2 3<br>1 5 4<br>2 3 5 | 5 0 0 |
| 2 3<br>1 2 3<br>0 1 2 | 1 1 1 |
