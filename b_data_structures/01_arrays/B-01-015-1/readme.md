# Обход матрицы змейкой

Дана матрица целых чисел. Выведите её элементы в порядке обхода змейкой: первая строка слева направо, вторая справа налево, третья слева направо и т.д.

## входные данные

В первой строке даны два натуральных числа __N__ и __M__ — количество строк и столбцов матрицы (1 ≤ N, M ≤ 1000).
Следующие __N__ строк содержат по __M__ целых чисел — элементы матрицы (-10^9 ≤ a[i][j] ≤ 10^9).

## выходные данные

Вывести элементы матрицы в порядке обхода змейкой, разделяя пробелами.

## ограничения

* 1 ≤ N, M ≤ 1000
* -10^9 ≤ a[i][j] ≤ 10^9
* time limit: 1s
* memory limit: 64m

## пример

| INPUT | OUTPUT |
| ----- | ------ |
| 3 3<br>1 2 3<br>4 5 6<br>7 8 9 | 1 2 3 6 5 4 7 8 9 |
| 2 4<br>1 2 3 4<br>5 6 7 8 | 1 2 3 4 8 7 6 5 |
| 4 2<br>1 2<br>3 4<br>5 6<br>7 8 | 1 2 4 3 5 6 8 7 |
