# Проверка палиндрома с помощью стека

Дана строка из строчных латинских букв. Определите, является ли она палиндромом, используя стек.

Палиндром — строка, которая одинаково читается слева направо и справа налево.

## входные данные

В единственной строке дана строка из строчных латинских букв длиной от 1 до 1000 символов.

## выходные данные

Выведите "YES", если строка является палиндромом, и "NO" в противном случае.

## ограничения

* 1 ≤ длина строки ≤ 1000
* Строка состоит только из строчных латинских букв
* time limit: 1s
* memory limit: 8m

## пример

| INPUT   | OUTPUT |
| ------- | ------ |
| racecar | YES    |
| hello   | NO     |
| a       | YES    |
| abba    | YES    |
