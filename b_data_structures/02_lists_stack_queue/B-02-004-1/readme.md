# Минимальный элемент в стеке

Реализуйте стек с операциями:

- `push X` — добавить число X в стек
- `pop` — удалить верхний элемент стека
- `min` — вывести минимальный элемент в стеке

Все операции должны выполняться за O(1).

## входные данные

Первая строка содержит число N (1 ≤ N ≤ 100000) — количество операций.

Следующие N строк содержат операции в формате:

- `push X` — добавить число X (-10^9 ≤ X ≤ 10^9)
- `pop` — удалить верхний элемент
- `min` — получить минимум

## выходные данные

Для каждой операции `min` выведите минимальный элемент в стеке на отдельной строке.

Гарантируется, что операции `pop` и `min` не будут вызываться для пустого стека.

## ограничения

* 1 ≤ N ≤ 100000
* -10^9 ≤ X ≤ 10^9
* time limit: 1s
* memory limit: 16m

## пример

| INPUT                                                | OUTPUT |
| ---------------------------------------------------- | ------ |
| 6<br>push 3<br>push 1<br>min<br>push 2<br>min<br>pop | 1<br>1 |
