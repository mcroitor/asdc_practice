# Следующий больший элемент

Для каждого элемента массива найдите следующий элемент справа, который больше текущего. Если такого нет, выведите -1.

Используйте стек для решения за O(N).

## входные данные

Первая строка содержит натуральное число N (1 ≤ N ≤ 100000) — количество элементов.

Вторая строка содержит N целых чисел — элементы массива.

## выходные данные

Выведите N чисел через пробел — для каждого элемента следующий больший или -1.

## ограничения

* 1 ≤ N ≤ 100000
* Элементы массива по модулю не превышают 10^9
* time limit: 1s
* memory limit: 16m

## пример

| INPUT          | OUTPUT         |
| -------------- | -------------- |
| 4<br>4 5 2 25  | 5 25 25 -1     |
| 5<br>5 4 3 2 1 | -1 -1 -1 -1 -1 |
| 4<br>1 2 3 4   | 2 3 4 -1       |
