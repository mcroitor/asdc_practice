# Циклическая очередь

Реализуйте циклическую очередь размером K с операциями:

- `enqueue X` — добавить число X в очередь (успешно, если есть место)
- `dequeue` — удалить и вывести первый элемент
- `size` — вывести текущее количество элементов

## входные данные

Первая строка содержит два числа N и K (1 ≤ N ≤ 100000, 1 ≤ K ≤ 1000) — количество операций и размер очереди.

Следующие N строк содержат операции в формате:

- `enqueue X` — попытка добавить число X (-10^9 ≤ X ≤ 10^9)
- `dequeue` — удалить и вывести первый элемент
- `size` — получить текущий размер

## выходные данные

Для операции `enqueue X`:

- Если элемент добавлен успешно, ничего не выводить
- Если очередь заполнена, вывести "overflow"

Для операции `dequeue`:

- Если очередь не пуста, вывести удалённый элемент
- Если очередь пуста, вывести "underflow"

Для операции `size` вывести текущее количество элементов.

## ограничения

* 1 ≤ N ≤ 100000
* 1 ≤ K ≤ 1000
* -10^9 ≤ X ≤ 10^9
* time limit: 1s
* memory limit: 8m

## пример

| INPUT                                                                                      | OUTPUT             |
| ------------------------------------------------------------------------------------------ | ------------------ |
| 8<br>3<br>enqueue 1<br>enqueue 2<br>enqueue 3<br>enqueue 4<br>size<br>dequeue<br>enqueue 5 | overflow<br>3<br>1 |
