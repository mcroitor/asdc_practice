# Поиск середины списка

Дан массив из N элементов. Найдите средний элемент (или два средних элемента, если N четное).

Используйте алгоритм "медленного и быстрого указателя" (tortoise and hare).

## входные данные

Первая строка содержит натуральное число N (1 ≤ N ≤ 1000) — количество элементов.

Вторая строка содержит N целых чисел, разделённых пробелами — элементы массива.

## выходные данные

Если N нечётное — выведите один средний элемент.

Если N чётное — выведите два средних элемента через пробел (в порядке их появления).

## ограничения

* 1 ≤ N ≤ 1000
* Элементы массива по модулю не превышают 10^9
* time limit: 1s
* memory limit: 8m

## пример

| INPUT            | OUTPUT |
| ---------------- | ------ |
| 5<br>1 2 3 4 5   | 3      |
| 6<br>1 2 3 4 5 6 | 3 4    |
| 1<br>42          | 42     |
