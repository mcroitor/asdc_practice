# Очередь на двух стеках

Реализуйте очередь с операциями:

- `enqueue X` — добавить число X в конец очереди
- `dequeue` — удалить и вывести первый элемент очереди
- `front` — вывести первый элемент очереди без удаления

Используйте только два стека для реализации.

## входные данные

Первая строка содержит число N (1 ≤ N ≤ 100000) — количество операций.

Следующие N строк содержат операции в формате:

- `enqueue X` — добавить число X (-10^9 ≤ X ≤ 10^9)
- `dequeue` — удалить и вывести первый элемент
- `front` — вывести первый элемент

## выходные данные

Для каждой операции `dequeue` и `front` выведите соответствующий элемент на отдельной строке.

Гарантируется, что операции `dequeue` и `front` не будут вызываться для пустой очереди.

## ограничения

* 1 ≤ N ≤ 100000
* -10^9 ≤ X ≤ 10^9
* time limit: 1s
* memory limit: 16m

## пример

| INPUT                                                    | OUTPUT      |
| -------------------------------------------------------- | ----------- |
| 5<br>enqueue 1<br>enqueue 2<br>front<br>dequeue<br>front | 1<br>1<br>2 |
