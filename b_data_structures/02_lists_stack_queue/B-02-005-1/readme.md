# Обратная польская нотация

Вычислите значение выражения, записанного в обратной польской нотации (постфиксной записи).

В постфиксной записи операторы следуют после операндов. Например:

- `2 3 +` означает `2 + 3`
- `2 3 + 4 *` означает `(2 + 3) * 4`

Поддерживаются операции: `+`, `-`, `*`, `/` (целочисленное деление).

## входные данные

В единственной строке дано выражение в постфиксной записи, состоящее из целых чисел и операторов `+`, `-`, `*`, `/`, разделённых пробелами.

## выходные данные

Выведите одно целое число — результат вычисления выражения.

Гарантируется, что выражение корректно и не содержит деления на ноль.

## ограничения

* Длина выражения не превышает 1000 символов
* Все числа по модулю не превышают 10^9
* Промежуточные результаты помещаются в тип int
* time limit: 1s
* memory limit: 8m

## пример

| INPUT                          | OUTPUT |
| ------------------------------ | ------ |
| 2 3 +                          | 5      |
| 2 3 + 4 *                      | 20     |
| 15 7 1 1 + - / 3 * 2 1 1 + + - | 5      |
