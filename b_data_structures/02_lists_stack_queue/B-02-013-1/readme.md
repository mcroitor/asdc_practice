# Стек на двух очередях

Реализуйте стек с операциями:

- `push X` — добавить число X в стек
- `pop` — удалить и вывести верхний элемент стека
- `top` — вывести верхний элемент стека без удаления

Используйте только две очереди для реализации.

## входные данные

Первая строка содержит число N (1 ≤ N ≤ 100000) — количество операций.

Следующие N строк содержат операции в формате:

- `push X` — добавить число X (-10^9 ≤ X ≤ 10^9)
- `pop` — удалить и вывести верхний элемент
- `top` — вывести верхний элемент

## выходные данные

Для каждой операции `pop` и `top` выведите соответствующий элемент на отдельной строке.

Гарантируется, что операции `pop` и `top` не будут вызываться для пустого стека.

## ограничения

* 1 ≤ N ≤ 100000
* -10^9 ≤ X ≤ 10^9
* time limit: 1s
* memory limit: 16m

## пример

| INPUT                                      | OUTPUT      |
| ------------------------------------------ | ----------- |
| 5<br>push 1<br>push 2<br>top<br>pop<br>top | 2<br>2<br>1 |
