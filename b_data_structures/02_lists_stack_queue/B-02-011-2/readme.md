# Генератор двоичных чисел

Сгенерируйте двоичные представления всех чисел от 1 до N, используя очередь.

Алгоритм: начните с "1" в очереди, затем для каждого элемента X создавайте X+"0" и X+"1".

## входные данные

В единственной строке дано натуральное число N (1 ≤ N ≤ 10000).

## выходные данные

Выведите N строк — двоичные представления чисел от 1 до N (каждое на отдельной строке).

## ограничения

* 1 ≤ N ≤ 10000
* time limit: 1s
* memory limit: 8m

## пример

| INPUT | OUTPUT |
| ----- | ------ |
| 5 | 1<br>10<br>11<br>100<br>101 |
| 3 | 1<br>10<br>11 |
