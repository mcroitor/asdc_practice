# Реверс списка

Дан массив из N целых чисел. Выведите элементы массива в обратном порядке.

## входные данные

Первая строка содержит натуральное число N (1 ≤ N ≤ 1000) — количество элементов в массиве.

Вторая строка содержит N целых чисел, разделённых пробелами — элементы массива.

## выходные данные

Выведите N чисел в одной строке через пробел — элементы массива в обратном порядке.

## ограничения

* 1 ≤ N ≤ 1000
* Элементы массива по модулю не превышают 10^9
* time limit: 1s
* memory limit: 8m

## пример

| INPUT          | OUTPUT    |
| -------------- | --------- |
| 5<br>1 2 3 4 5 | 5 4 3 2 1 |
| 3<br>10 -5 7   | 7 -5 10   |
