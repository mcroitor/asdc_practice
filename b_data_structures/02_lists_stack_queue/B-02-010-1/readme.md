# Слияние двух отсортированных списков

Даны два отсортированных по возрастанию массива. Объедините их в один отсортированный массив.

## входные данные

Первая строка содержит два числа N и M (1 ≤ N, M ≤ 1000) — размеры первого и второго массивов.

Вторая строка содержит N целых чисел в порядке возрастания — элементы первого массива.

Третья строка содержит M целых чисел в порядке возрастания — элементы второго массива.

## выходные данные

Выведите N+M чисел через пробел — элементы объединённого отсортированного массива.

## ограничения

* 1 ≤ N, M ≤ 1000
* Элементы массивов по модулю не превышают 10^9
* Массивы отсортированы по возрастанию
* time limit: 1s
* memory limit: 8m

## пример

| INPUT | OUTPUT |
| ----- | ------ |
| 3 3<br>1 3 5<br>2 4 6 | 1 2 3 4 5 6 |
| 2 4<br>1 2<br>3 4 5 6 | 1 2 3 4 5 6 |
